# Drevan

Drevan is a text-driven browser RPG inspired by early-2000s web games such as Alien Adoption Agency. Prepare in The Quarters, train in Dominion, fish at The Driftwater, or explore The Ruins in a world where old machinery and magic still work side by side.

> The old world is gone. The unknown awaits.

The game uses Node.js, TypeScript, Express, and EJS for server-rendered pages, SQLite and Drizzle for persistence, and Sass for styling. Yarn manages dependencies and development commands.

Start with [Run Drevan locally](docs/development/getting-started.md) to install dependencies, initialize the local catalog, and make a test account. Use the [contributor workflow](docs/development/workflow.md) before submitting changes.
