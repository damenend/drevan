# Drevan terminology

Use these names and articles in player-facing labels, directory links, and documentation. See [lore](lore.md) for setting details and the [writing guide](writing-guide.md) for voice.

| Name             | Refers to                                       |
| ---------------- | ----------------------------------------------- |
| Drevan           | The game and its world                          |
| Nexaris          | The settlement and signed-in location directory |
| The Quarters     | The character dashboard                         |
| Dominion         | The arena and training grounds                  |
| Curious Emporium | The shop, also called the Emporium in prose     |
| Sanctum          | The healing location                            |
| The Driftwater   | The fishing location                            |
| The Registry     | The player directory                            |
| The Reliquary    | The lore library                                |
| The Ruins        | The expedition location                         |
| Recall Beacon    | The item that returns an explorer to Nexaris    |

Use Strength, Agility, Intellect, and Fortitude for primary attributes. Use Attack Power, Speed, and Defense for combat stats. Use HP for health, XP for experience, and spell out attribute points where space allows. AP abbreviates attribute points in playtest reports. In technical documentation, PvE means player versus environment and PvP means player versus player.

Use **Unaligned** for the displayed class and `unaligned` for its stored identifier. Melee, Ranged, and Caster are future specializations. Use **Floor 1** and **Floor 2** for dungeon floors. Use **Log in** and **Log out** for actions.
